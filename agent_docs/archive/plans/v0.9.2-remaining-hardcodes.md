# Plan: v0.9.2 — Remaining Hardcode Fixes

## Status

COMPLETED in working tree (2026-02-25, pending commit/PR).

## Goal

Eliminate all remaining hardcoded formatting values identified during the full
repository audit of 2026-02-25. After this, the only non-LaTeX-driven values
in the codebase should be documented fallback defaults in
`RenderProfile::from_layout()`.

## Outcome Snapshot

- All 13 audit items are implemented in parser/model/renderer.
- New `DocumentLayout` fields were added and propagated through
  `RenderProfile::from_layout()`.
- Paired parser + renderer unit tests were added/updated.
- Local quality gate is green (`fmt`, `clippy -D warnings`, `test --workspace`).
