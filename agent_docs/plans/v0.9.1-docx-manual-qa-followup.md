# Plan: v0.9.1 DOCX Manual-QA Follow-up

## Status

PARTIALLY COMPLETED (WIP stabilized and merged as PR #28; remaining parity items are tracked in `v0.9.3-docx-parity-disstyles-wave2.md`).

## Goal

Close the remaining semantic/visual gaps discovered during manual DOCX review, while keeping implementation strictly LaTeX-driven and reusable for arbitrary LaTeX projects.

## Non-negotiable constraints

1. No project-specific renderer hardcodes.
2. Every formatting behavior must be traceable to:
   - parsed LaTeX source semantics, and/or
   - explicit project config, mapped through `DocumentLayout`.
3. Renderer defaults are fallback-only.

## Current WIP Snapshot

1. `ferritex-core`:
   - parse mode now supports preserving reference nodes for renderer-side hyperlinking,
   - standalone `\label{...}` attachment added,
   - initial citation repeat handling (`Там же.` / `Указ. соч.`) added,
   - initial bibliography-entry injection after bibliography heading added,
   - list extraction expanded with `itemindent`/`leftmargin` and partial `\dimexpr`.
2. `DocumentLayout`:
   - new field `list_item_indent_twips`.
3. `ferritex-renderer-docx`:
   - bookmark/reference index infrastructure,
   - partial internal hyperlink support for references and TOC entries,
   - first-line-indent adjustments for headings/lists,
   - source/caption/table rendering refinements.
4. Build baseline (updated 2026-02-24):
   - parser lifetime blocker (`E0515`) in list parameter extraction is fixed,
   - workspace quality gate is green (`fmt`/`clippy -D warnings`/`test`).
5. Title-page parser extraction improvements (updated 2026-02-24):
   - `titlepage` is now handled in text-flow style state (same path as `titlingpage`),
   - leading `\vspace{...}` in mixed title-page chunks maps to paragraph `space_before`,
   - spacing-factor parsing expanded to `\setstretch{...}` and `\linespread{...}`,
   - `\fontsize{<size>}{<baseline>}` now maps baseline to paragraph line-spacing override,
   - global layout spacing extraction is restricted to preamble to avoid body-local overrides.
6. Title/TOC/manual-QA follow-up improvements (updated 2026-02-24):
   - `ParagraphStyle` now supports `left_indent_twips` for parser-driven block offsets,
   - `flushright + tabular{l}` title-page blocks are mapped to left-indented DOCX paragraphs (generic estimate, no corpus hardcode),
   - spaces around explicit `\\` line breaks are normalized to remove synthetic shifts on title-page multiline blocks,
   - memoir `\sethangfrom{\noindent #1}` now maps to heading justify alignment (`both`),
   - TOC entry/header/style line spacing now follows `DocumentLayout.body_line_spacing_twips` (instead of hardcoded single spacing).
7. Spacing-command extraction updated (2026-02-24, WIP):
   - parser now treats memoir/setspace spacing commands as size-aware factors (`\OnehalfSpacing`, `\DoubleSpacing`, `\SingleSpacing`, lowercase variants),
   - title-page spacing directives reuse the same extraction path as document-level spacing (no special-case hardcode),
   - 14pt memoir one-half spacing is calibrated to avoid over-compression on DOCX title-page multiline blocks.
8. TOC chapter-spacing mapping updated (2026-02-24, WIP):
   - parser extracts `\cftbeforechapterskip` into `DocumentLayout.toc_chapter_space_before_twips`,
   - memoir default chapter TOC skip is applied when explicit value is absent,
   - renderer adds this spacing before numbered TOC chapter entries (`ГЛАВА ...`).

## Workstreams

1. Stabilize WIP and restore build health:
   - fix parser lifetime bug and reconcile changed function signatures,
   - run `cargo fmt`, `cargo clippy`, `cargo test`.

2. Title page spacing parity:
   - verify parser captures line spacing and vertical spacing directives used in title-page blocks,
   - map through `ParagraphStyle`/`DocumentLayout` without template hardcoding.

3. TOC parity + active navigation:
   - finish TOC style details (indents/separators/bold flags/leaders),
   - ensure TOC entries hyperlink to actual section anchors.

4. First-line indentation correctness:
   - ensure only first line is indented (not full paragraph shift) for:
     - numbered lists,
     - unordered lists,
     - numbered section headings.

5. Math rendering upgrade:
   - move from plain-text approximation to DOCX equation representation (OMML path),
   - keep fallback behavior deterministic when conversion is impossible.

6. Footnote citation semantics:
   - finish LaTeX-style repeat rules (`Там же.`, `Указ. соч.` and related cases),
   - back with parser + renderer tests and fixture coverage.

7. Figure/table source and caption polish:
   - keep caption justification behavior,
   - remove incorrect left tab/indent shifts where not requested by LaTeX,
   - apply dedicated style for `Источник:` lines.

8. Table readability improvements:
   - continue mapping LaTeX table-related style intent into DOCX table/cell paragraph settings.

9. Bibliography section completion:
   - ensure bibliography heading and entries are rendered reliably,
   - support expected ordering/formatting behavior from parsed bibliography metadata.

10. Body cross-reference hyperlinks:
    - chapter/section/table/figure/appendix references in text must become active internal links.
