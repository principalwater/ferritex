### Sub-task A — Block::TableOfContents (CRITICAL)

**Problem**: `\tableofcontents` → `Block::Section { title: "ОГЛАВЛЕНИЕ" }` contaminates AST
with Russian. Renderer detects TOC via `is_toc_heading()` string match.

**Fix**: Emit `Block::TableOfContents` AST node; detect via type in renderer.

#### Files to change

**`crates/ferritex-core/src/model/mod.rs`**
- Add to `enum Block` after `BibliographyHeading`:
  ```rust
  /// Position where \tableofcontents was declared.
  /// Renderer expands this into generated TOC paragraphs.
  /// No language-specific text stored — AST node type is the signal.
  TableOfContents,
  ```

**`crates/ferritex-core/src/parser/latex.rs`**
- `try_parse_structural_heading_command` (~line 6250): replace body with:
  ```rust
  if command.starts_with("\\tableofcontents") {
      Some(Block::TableOfContents)
  } else {
      None
  }
  ```
  Remove now-unused parameters (autocite_mode, metadata, preserve_dynamic_markers).
  Update call site (~line 322) accordingly.
- Add doc comment to `is_plain_front_matter_heading` (~line 6322) explaining it handles
  only legacy plain-text Russian headings; `\tableofcontents` uses Block::TableOfContents.

**`crates/ferritex-renderer-docx/src/lib.rs`**
- Delete `fn is_toc_heading` (~line 2045).
- Main render loop (~line 840): replace the `Block::Section` arm's TOC special-case
  with a new arm:
  ```rust
  Block::TableOfContents => {
      for toc_para in generated_toc_paragraphs(document, index, &profile, &ref_index) {
          docx = docx.add_paragraph(toc_para);
      }
  }
  ```
- `generated_toc_paragraphs` (~line 2073): remove `is_toc_heading` filter.
- `generated_toc_paragraphs_from_entries` (~line 2113): remove `is_toc_heading` filter.
- `ReferenceRenderIndex::from_document` (~line 617): add `Block::TableOfContents` to the
  no-op arm.
- Any exhaustive `match` on `Block` (e.g. in `build_paragraph`): add `Block::TableOfContents => unreachable!()`.

**Tests**
- `parser_latex_tests.rs`: update `test_tableofcontents_command_becomes_heading_block`
  → assert `matches!(&doc.blocks[0], Block::TableOfContents)`.
- Add `test_tableofcontents_with_asterisk_becomes_toc_node`.
- `renderer_docx_tests.rs`: update `generated_toc_paragraphs_include_chapters_and_sections`
  → replace `Block::Section { title: "ОГЛАВЛЕНИЕ" }` with `Block::TableOfContents`.

**Commit message**:
```
fix: replace string-matching TOC detection with Block::TableOfContents AST node

\tableofcontents now emits Block::TableOfContents instead of Block::Section
with Russian text. Renderer detects TOC via AST node type.
Removes is_toc_heading() string-match function entirely.
```

### Sub-task B — list labelsep em_twips scaling (HIGH)

**Problem**: `layout.list_label_sep_twips.unwrap_or(142)` — magic number, assumes 14pt.

**File**: `crates/ferritex-renderer-docx/src/lib.rs` line ~202

**Fix** (inline formula, no cross-crate dependency needed):
```rust
let sep = layout.list_label_sep_twips.unwrap_or_else(|| {
    // 0.5em in twips, scaled to actual body font size.
    // Same formula as em_twips_for_body_font() in ferritex-core.
    let body_hp = layout.font_size_body_hp.unwrap_or(28) as f64;
    (body_hp / 2.0 * 20.0 * 0.5).round() as i32
});
```

**Test**: add `test_list_label_sep_fallback_scales_with_font_size` in renderer tests:
- Layout with `font_size_body_hp: Some(24)` (12pt), no `list_label_sep_twips`
- Expected `sep = (12.0 * 20.0 * 0.5).round() = 120`

**Commit message**:
```
fix: scale list labelsep fallback with actual body font size

Replace magic constant 142 (0.5em at 14pt) with inline em computation
using layout.font_size_body_hp so the default is font-agnostic.
```

### Sub-task C — bibliography title language-aware (HIGH)

**Problem**: `try_parse_bibliography_command` defaults to "СПИСОК ЛИТЕРАТУРЫ" for any language.

**File**: `crates/ferritex-core/src/parser/latex.rs`

**Fix**:

1. Add function after `default_chapter_name_for_language`:
   ```rust
   /// Returns the default bibliography section title for the given BCP-47 language tag.
   /// Fallback when \printbibliography has no `title=` argument.
   fn default_bibliography_title_for_language(language: Option<&str>) -> &'static str {
       match language {
           Some("ru-RU") => "СПИСОК ЛИТЕРАТУРЫ",
           Some("uk-UA") => "СПИСОК ЛІТЕРАТУРИ",
           Some("be-BY") => "СПІС ЛІТАРАТУРЫ",
           Some("en-US") | Some("en-GB") => "REFERENCES",
           Some("de-DE") => "LITERATURVERZEICHNIS",
           Some("fr-FR") => "BIBLIOGRAPHIE",
           Some("es-ES") => "BIBLIOGRAFÍA",
           Some("it-IT") => "BIBLIOGRAFIA",
           Some("pt-BR") => "REFERÊNCIAS",
           Some("tr-TR") => "KAYNAKLAR",
           _ => "REFERENCES",
       }
   }
   ```

2. Change `try_parse_bibliography_command` signature to accept `language: Option<&str>`.
   Replace `let default_title = "СПИСОК ЛИТЕРАТУРЫ".to_string()` with
   `let default_title = || default_bibliography_title_for_language(language).to_string()`.

3. Update call site (~line 330) to pass `layout.document_language.as_deref()`.
   (`layout` is already in scope there.)

**Tests** in `parser_latex_tests.rs`:
- `test_bibliography_default_title_english`: babel `[english]` + `\insertbibliofullsorted` → `"REFERENCES"`
- `test_bibliography_default_title_russian`: babel `[russian]` → `"СПИСОК ЛИТЕРАТУРЫ"`
- `test_bibliography_explicit_title_overrides_language`: `\printbibliography[title=Works Cited]` → `"Works Cited"`

**Commit message**:
```
fix: derive default bibliography title from document language

Add default_bibliography_title_for_language() following the same pattern
as default_chapter_name_for_language(). Falls back to "REFERENCES" for
unknown/absent language. Russian is no longer the hardcoded default.
```

### Sub-task D — gate dissertation counter fallbacks (MEDIUM)

**Problem**: `apply_known_counter_fallbacks` runs Russian dissertation template replacement
for ANY document, not just dissertations.

**Files**:
- `crates/ferritex-core/src/parser/latex.rs`
- `AGENTS.md`

**Fix**:

1. Add `document_class: Option<String>` to `ParseMetadata` struct.
   Populate in `collect_parse_metadata` by calling `extract_documentclass_name(&source)`.

2. In `apply_known_counter_fallbacks`, add early return:
   ```rust
   // DISSERTATION-SPECIFIC: patterns below match Russian dissertation template.
   // Gated on document class to avoid false positives for other documents.
   let is_dissertation = metadata
       .document_class
       .as_deref()
       .map(|c| c.eq_ignore_ascii_case("disser") || c.to_lowercase().contains("dissert"))
       .unwrap_or(false);
   if !is_dissertation {
       return text.to_string(); // no-op for non-dissertation classes
   }
   ```

3. Update `AGENTS.md` policy table / notes section:
   ```
   Known exception — apply_known_counter_fallbacks (parser/latex.rs ~4008–4064):
   Contains dissertation-specific Russian counter templates. Gated on document_class
   containing "disser*". Safe for all other document classes (early return).
   ```

**Test** in `parser_latex_tests.rs`:
- `test_counter_fallbacks_skipped_for_non_dissertation_class`:
  document with `\documentclass{article}` containing the placeholder string
  "Диссертация состоит из введения..." → string is returned unchanged.

**Commit message**:
```
fix: gate dissertation-specific counter fallbacks on document class

apply_known_counter_fallbacks() now checks document_class contains "disser"
before applying Russian dissertation template replacements. All other document
classes are unaffected. Documents exception in AGENTS.md.
```
