## Goal

Close the next parity wave between canonical LaTeX PDF and ferritex DOCX for a large multi-file dissertation-style project, while keeping implementation 100% LaTeX-driven and reusable.

## Non-negotiable constraints

1. No corpus-specific hardcodes in renderer code.
2. Every visual fix must go through:
   - parser extraction in `ferritex-core`,
   - `DocumentLayout` field(s),
   - `RenderProfile::from_layout()` mapping,
   - renderer consumption.
3. Add paired tests (present extraction + absent/fallback + renderer behavior).

## Input for this wave (from user manual QA)

1. List indentation/justification mismatch for ordered and unordered lists.
2. Title page block/layout mismatch (header + central title/degree block).
3. TOC page-fill mismatch (entry density/pagination differs from PDF/manual DOCX).
4. Math formulas not supported as native Word equations.
5. Appendix portrait/landscape and explicit page-break behavior missing.
6. Table font fidelity still incomplete.
7. “Объем и структура работы” text counters mismatch with produced DOCX pagination/counts.
8. “Публикации по теме исследования” section rendered incorrectly.
9. Superscript citation markers visually detached from text.

## Workstreams

### 1) Lists parity (indent + full justification)

- Audit `enumitem`/`\setlist` extraction for:
  - `leftmargin`, `itemindent`, `labelsep`, `labelwidth`, `listparindent`
- Ensure list paragraphs use correct first-line/hanging behavior and justified alignment.
- Add parser and renderer tests for multi-line list items.

### 2) Title page micro-layout parity

- Re-audit title-page parser logic against style files (`disstyles.tex` and any variant such as `disstylesx.tex` when present in project tree).
- Ensure top block and central title/degree blocks preserve:
  - alignment,
  - before/after spacing,
  - line spacing,
  - first-line indent and explicit line breaks.
- Add fixture coverage for representative title-page macros (`flushright+tabular`, `\vspace`, `\fontsize`).

### 3) TOC density/pagination parity

- Audit all TOC spacing contributors:
  - TOC style line spacing,
  - `toc_chapter_space_before_twips`,
  - TOC entry before/after spacing,
  - tab-stop calculations and hanging indent width.
- Validate against PDF/manual DOCX page break around late chapter entries.
- Add deterministic test on generated TOC XML spacing parameters.

### 4) Math upgrade (OMML)

- Implement parser->renderer math path for native DOCX equations where possible.
- Keep deterministic fallback to text approximation for unsupported constructs.
- Add renderer tests for inline and display equations.

### 5) Appendix page layout + forced breaks

- Parse and propagate relevant page-layout markers:
  - orientation switches (portrait/landscape),
  - explicit break commands.
- Emit correct DOCX section/page break structure (no invalid mid-flow `sectPr` usage).
- Add regression tests for mixed-orientation appendix fragments.

### 6) Table typography parity

- Audit table font source precedence:
  - global body font size,
  - `\SetTblrInner{font=...}`,
  - caption/table-specific overrides.
- Ensure table cell runs and table paragraphs apply expected font family/size/weight.
- Add tests for mixed table font scopes.

### 7) Counter-driven prose blocks

- Audit parser behavior for macro-generated narrative counters (pages, figures, tables, bibliography count).
- Ensure values come from LaTeX semantics and available metadata, not static fallback text.
- Document limitation clearly when DOCX pagination cannot match PDF pagination exactly.

### 8) Publications section robustness

- Identify unsupported macros/environments in “Публикации по теме исследования” block.
- Extend parser normalization for these constructs in a generic way.
- Add fixture from anonymized synthetic variant of the same construct pattern.

### 9) Superscript citation spacing

- Audit run assembly around footnote/citation superscripts.
- Remove synthetic extra spaces before superscript runs.
- Add renderer test asserting no detached spacing around superscript markers.
